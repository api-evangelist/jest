<p>We are excited to present the <strong>new Jest website</strong>!</p>
<p>The Jest site was upgraded from <strong><a class="" href="https://v1.docusaurus.io/" rel="noopener noreferrer" target="_blank">Docusaurus 1</a></strong> to <strong><a class="" href="https://v2.docusaurus.io/" rel="noopener noreferrer" target="_blank">Docusaurus 2</a></strong>, and is an early adopter of the <a class="" href="https://v2.docusaurus.io/blog/2021/03/09/releasing-docusaurus-i18n" rel="noopener noreferrer" target="_blank">newly released Docusaurus 2 i18n support</a>.</p>
<p>So, what's new exactly?</p>
<h2 class="anchor anchorTargetStickyNavbar_tleR" id="whats-new">What's new?<a class="hash-link" href="https://jestjs.io/blog/2021/03/09/jest-website-upgrade#whats-new" title="Direct link to What's new?">​</a></h2>
<p>Here's a good overview of the most visible improvements:</p>
<ul>
<li class="">
<p><strong>Dark Mode</strong>: change the color scheme through the navbar switch.</p>
</li>
<li class="">
<p><strong>Modern navigation</strong>: we improved the navigation experience with <strong>client-side routing</strong> and <strong>prefetching</strong>.</p>
</li>
<li class="">
<p><strong>Versions dropdown</strong>: it is now simpler to switch from one Jest version to another.</p>
</li>
<li class="">
<p><strong>Progressive-Web-App</strong>: you can install the Jest website and browse it offline.</p>
</li>
<li class="">
<p><strong>Search</strong>: try the new Algolia <strong>DocSearch v3</strong> user-experience. It is now possible to <strong>search in blog posts</strong>.</p>
</li>
<li class="">
<p><strong>I18n</strong>: Jest is the first website using the <strong><a class="" href="https://v2.docusaurus.io/docs/i18n/introduction" rel="noopener noreferrer" target="_blank">new i18n feature of Docusaurus 2</a></strong>. It is now possible to <strong>translate blog posts</strong>.</p>
</li>
<li class="">
<p><strong>MDX</strong>: embedding React components in Markdown will allow maintainers to make the <strong>documentation more interactive</strong>.</p>
</li>
</ul>
<h2 class="anchor anchorTargetStickyNavbar_tleR" id="for-site-translators">For site translators<a class="hash-link" href="https://jestjs.io/blog/2021/03/09/jest-website-upgrade#for-site-translators" title="Direct link to For site translators">​</a></h2>
<p>If you want to help to translate the new Jest website, please use the new Crowdin project <a class="" href="https://crowdin.com/project/jest-v2" rel="noopener noreferrer" target="_blank">jest-v2</a> instead of the previous one.</p>
